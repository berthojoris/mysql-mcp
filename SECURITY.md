# Security Policy

## Supported Versions

Only the latest published version of `@berthojoris/mcp-mysql-server` receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately via [Private Vulnerability Reporting](https://github.com/berthojoris/mysql-mcp/security/advisories/new).

Do not open public issues with vulnerability details.

When reporting, please include:

- The `@berthojoris/mcp-mysql-server` version
- The permissions/categories configuration in use
- Steps to reproduce, or the tool and input involved
- The impact you observed or expect

## Response and Disclosure

- We aim to acknowledge reports within 7 days.
- Fixes are validated against the reported configuration before release.
- We follow coordinated disclosure; public disclosure happens only after a fix is released and agreed with the reporter.
